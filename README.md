# RobotArm Project: SO-ARM101 Control & Simulation

![ROS2](https://img.shields.io/badge/ROS_2-Humble-green)

A robotic arm control system designed for the **SO-ARM101** (6-DOF) robotic arm. This project serves as a research and development platform for exploring inverse kinematics, manual control, and reinforcement learning using ROS 2 and NVIDIA Isaac Sim.

##  Project Goal
The primary goal of this project is to develop a robust control system for the SO-ARM101 to perform autonomous pick-and-place tasks. The long-term vision involves training the arm using **Reinforcement Learning (RL)** in **Isaac Sim**—simulating ~100 robots in parallel to speed up training—to use a laptop camera to detect a can, pick it up, and place it into a box.

##  Hardware Setup

- **Robot ArmModel**: SO-ARM101 (5 degrees of freedom + Gripper)
- **Actuators**: LewanSoul LX-16A Serial Bus Servos (x6)
- **Controller**: Hiwonder TTL / USB Debugging Board
- **Power Supply**: 12V 2.5A (5-cell Li-Po battery recommended)
- **Communication**: USB Serial (COM port)

###  Known Hardware Issues
> [!WARNING]
> **Thermal Deformation**: Some 3D printed components currently suffer from warping due to the heat generated by the LX-16A servos. These parts need to be reprinted with heat-resistant material (ABS/PETG/ASA).
>
> **Motion Jitter**: The arm currently experiences jittery movement and does not yet utilize its full range of motion. Smoothing algorithms and PID tuning are planned.

##  Software & Primary Scripts

The project can be run in **Standalone Mode** (Python/Tkinter only) or **ROS 2 Mode**.

### Key Scripts in `src/`

| Script Name | Description |
| :--- | :--- |
| **`robot_arm_gui.py`** | **Main Standalone GUI**. Provides manual slider control, inverse kinematics (IK) positioning, and a real-time 3D matplotlib visualization of the arm. Does not require ROS 2. |
| **`Ros2Version1.py`** | **ROS 2 Integrated GUI**. Similar to the standalone version but wraps the application in a ROS 2 Node (`robot_arm_gui`), publishing/subscribing to `/joint_states`. |
| `lx16a_servo_control.py` | **Hardware Test Script**. Simple script to verify servo connection and movement limits. Use this to test motors individually. |
| `lx16a_IK_control.py` | Testing script for inverse kinematics logic without the full GUI overhead. |

##  Installation & Usage

### 1. Prerequisites
- Python 3.10+
- ROS 2 Humble (optional, for ROS features)
- Drivers for USB-to-TTL Serial Controller

### 2. Install Dependencies
```bash
pip install numpy matplotlib pyserial
# Install the custom servo library
pip install pylx16a
```
*Note: Ensure `lewansoul_lx16a` or `pylx16a` is correctly configured for your environment.*

### 3. Running the Project

**Option A: Standalone GUI (No ROS)**
Use this for testing hardware connection and IK mechanics.
```bash
cd RobotArm/src
python robot_arm_gui.py
```
*If hardware is not connected, it will default to **Simulation Mode**.*

**Option B: ROS 2 Control**
Ensure your ROS 2 environment is sourced.
```bash
cd RobotArm/src
python Ros2Version1.py
```
